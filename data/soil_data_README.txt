soil data readme

These data are from - https://www.usgs.gov/publications/soil-property-and-class-maps-conterminous-united-states-100-meter-spatial-resolution

with publication - https://acsess.onlinelibrary.wiley.com/doi/10.2136/sssaj2017.04.0122

and github page - https://github.com/aramcharan/US_SoilGrids100m

Downloaded from - https://scholarsphere.psu.edu/resources/ea4b6c45-9eba-4b89-aba6-ff7246880fb1

The data are a machine learning-based data assimilation/prediction product on a 100m spatial grid. 

The file names describe the variable and depth codes sl1, ..., sl7 which refer depths of 0, 5, 15, 30, 60, 100, and 200 cm respectively. 

These data have been extracted and saved in './data/soil_covariates.rds' using the script 'extract_soil_covariates.rds'
